# Instructions

The procedure for building a course is [docs/PLAYBOOK.md](docs/PLAYBOOK.md); the technical lessons behind the engine
are [docs/LESSONS.md](docs/LESSONS.md). An agent asked to "read instructions.md and build course XYZ" should follow the
playbook.

Branches, commits and pull requests follow [CONTRIBUTING.md](CONTRIBUTING.md). Use one branch per course, carrying
only `courses/<slug>/`, and put engine fixes on their own branch, test first. Open draft PRs only. Commit messages and
PR bodies carry no AI attribution. Start the multi-agent research and QA workflows only when the user asks for them
(docs/PLAYBOOK.md §0).
